# Craigslist housing image manifest

All files in this folder are **AI-generated style samples** for Verdansc Craigslist operators. They are **not** photographs of a specific vacant unit, street address, or property Verdansc manages. Do not present them as a real listing you control.

Repo `public/` only contains Next.js default SVGs (no owned property photos). These generated images are the original assets for this pack.

## Suggested Craigslist attach order (housing wanted)

Use **6 photos**. First photo becomes the thumbnail.

Daily rotation (slots S02–S32, start 2026-09-03) lists a 6-photo order in each `../variants/day-0N.md`. Default set (S02):

1. `nob-hill-courtyard-apartments.png` (thumbnail — area look)
2. `downtown-abq-loft-exterior.png`
3. `downtown-abq-loft-interior.png`
4. `rio-rancho-apartment-exterior.png`
5. `rio-rancho-flat-kitchen.png`
6. `abq-balcony-sandia-view.png`

If the post is loft-specific, start with `downtown-abq-loft-exterior.png`. If Rio Rancho-specific, start with `rio-rancho-apartment-exterior.png`.
